# Step 1: Inspect the scene

**Goal:** see what is in the scene before changing anything.

**By hand:** look at the **Outliner** (top right). Each row is an object. The default scene has a Cube, a Light and a Camera.

**Concepts**
- **Object:** anything in the scene (mesh, light, camera, armature).
- **Object Mode:** the default mode, where you move and select whole objects.
- **Location / size:** shown in the sidebar (press **N** in the 3D viewport, then the *Item* tab).
